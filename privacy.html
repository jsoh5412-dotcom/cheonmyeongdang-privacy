개인정보처리방침

시행일: 2026년 11월 1일
대상: 천명당 에이전트(구글 OAuth 앱)

1. 앱이 하는 일

천명당 에이전트는 천명당 운영자가 혼자 쓰는 내부 업무 도구입니다. 구글 계정은 운영자 본인 것 하나만 연결합니다.

2. 구글 데이터를 쓰는 범위

  • 구글 드라이브: 운영자가 만든 결과지 PDF를 운영자 본인 드라이브에 올리고 보관하는 데만 씁니다.
  • 지메일: 운영자 본인 지메일 계정에서 결과지 PDF를 첨부해 보내는 데만 씁니다.

이 밖의 용도로 구글 데이터를 읽거나 쓰지 않습니다.

3. 다른 사람의 구글 데이터

운영자가 아닌 다른 사람의 구글 계정 데이터는 수집·저장·공유하지 않습니다. 다른 사람이 이 앱에 구글 계정으로 로그인하는 기능도 없습니다.

4. 보관과 공유

앱이 다루는 파일은 운영자 본인의 구글 드라이브와 지메일 안에만 남습니다. 구글 데이터를 제3자에게 팔거나 넘기지 않으며, 광고에 쓰지 않습니다. 구글 API로 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

5. 접근 해제

운영자는 언제든 구글 계정의 서드파티 액세스 설정에서 이 앱의 접근 권한을 해제할 수 있습니다.

Privacy Policy

Effective date: November 1, 2026
Applies to: Cheonmyeongdang Agent (Google OAuth app)

1. What the app does

Cheonmyeongdang Agent is an internal tool used solely by the operator of Cheonmyeongdang. Only the operator's own Google account is connected.

2. How Google data is used

  • Google Drive: used only to upload and store result PDFs created by the operator in the operator's own Drive.
  • Gmail: used only to send those result PDFs as attachments from the operator's own Gmail account.

Google data is not read or used for any other purpose.

3. Other people's Google data

The app does not collect, store, or share Google user data of anyone other than the operator. There is no feature for other people to sign in with Google.

4. Retention and sharing

Files handled by the app remain only in the operator's own Google Drive and Gmail. Google data is never sold, transferred to third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access

Access can be revoked at any time at Google Account third-party access settings.
